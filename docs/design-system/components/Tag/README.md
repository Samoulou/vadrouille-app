# Tag

Étiquette qui signale une exception sur un arrêt, un repas ou un événement : quelque chose à faire ou à vérifier.

## Variantes

- **À réserver** : aplat `quai`, texte `on-quai`, style `etiquette`, coins `radius-tag`. Une action de la personne est nécessaire.
- **À confirmer** / **Non confirmé** : fond transparent, contour pointillé 1,5 px `ink`, texte `ink`. L'information n'a pas pu être vérifiée.
- **Compteur** : carré `quai` de 24 px avec un nombre en 800, à côté d'un titre (« À faire avant de partir » 4).

## Règles

- Pas de tag pour ce qui est normal : pas de « Vérifié », « Gratuit » ou « Ouvert ». Ces informations vont dans les métadonnées.
- Au plus deux tags par arrêt.
- Le jaune n'apparaît que pour une action requise.
- Le texte du tag est en minuscules (sauf l'initiale), jamais en capitales.

## Ce que fournit l'appelant

Le type de tag et, pour le compteur, le nombre.
