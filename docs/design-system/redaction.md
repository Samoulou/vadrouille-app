# Rédaction

Le produit parle comme un ami qui connaît bien la ville : il tutoie, va droit au but, justifie ses choix en une phrase et ne promet jamais ce qu'il n'a pas vérifié.

## Voix

- Tutoiement, phrases courtes, verbes d'action.
- Chaque recommandation dit pourquoi, en une ligne qui commence par ce que la personne a demandé : « Tu as choisi Histoire et Balades en ville. »
- Pas de point d'exclamation, pas de superlatif (« incroyable », « incontournable »), pas d'emoji.
- L'incertitude est dite simplement : « Horaire à confirmer », jamais cachée.
- Une erreur dit ce qui s'est passé et ce qu'on peut faire : « Les temps de trajet n'ont pas pu être recalculés. Ton programme précédent est conservé. »

## Vocabulaire fixe

Une action garde le même nom de bout en bout.

| Contexte | Mots | Jamais |
|---|---|---|
| Présentation | J'aime / Pas pour moi ; Je choisis / Option suivante (repas) ; Passer | Like, swiper, valider |
| Programme | Garder / Remplacer ; Appliquer / Annuler ; Verrouiller | Supprimer une étape, OK |
| Réservations | À réserver ; Réserver ; Déjà réservé | Booker |
| Incertitude | À confirmer ; Non confirmé | Peut-être, environ (pour une date) |
| Logement | Logement, hôtel ; quartier | Hébergement |
| Paiement | Débloquer ; Payer avec TWINT ; Payer par carte | Acheter maintenant, Premium |

## Formats

- Dates : « dim. 30.08 » dans les listes, « Dimanche 30 août » en titre.
- Heures : « 10:45 », créneaux « 10:45 – 11:45 ».
- Durées : « 45 min », « 1 h 30 ».
- Prix : « environ 35 CHF par personne » ; un montant estimé est toujours précédé de « environ » ou « ≈ ».
- Jours : « J1 », « J2 » dans les pastilles, « Jour 2 » dans les phrases.
- Contenu non vérifié dans les maquettes : entre crochets, « [Distillerie] ».
